# Track every second
The Focus plugin allows you to track how much time you spend working and then distribute it among projects, to keep organized. Along side that, you can set goals and challenge yourself to keep working.

# What's Tasker?
Tasker is a plugin powered productivity platform, where you shape your unique productivity workflow by installing plugins you find useful. This is one of those plugins and even if you can't find the perfect plugin, we have developer tools and documentation available, to get you started in creating your own plugins, with minimal experience needed. Get started with Tasker [here](https://github.com/Firepixel85/Tasker-Labs)

# Installation & Requirements

### Requirements
The only thing you need to download this plugin is an internet connection and Tasker 2.0 installed on your computer. You can download Tasker [here](https://github.com/Firepixel85/Tasker-Labs/releases/latest)

### Installation
1. Go to the [latest release](https://github.com/Rosepen-Studios/Focus/releases/latest) and download for the assets a file named <code>plugin.zip</code> (or click [here])
2. Open Tasker and go to the plugins view (<code>⌘P</code> or click the puzzle icon on the bottom-left)
3. Open the plugin folder (<code>⌘⇧O</code> or click the folder icon on the bottom-right)
4. Extract the zip file you downloaded and place it's contents (<code>focus</code>) inside the <code>plugins</code> folder you opened on step 3
5. Go back to Tasker and refresh the plugins view (<code>⌘⇧R</code> or click on the circling arrows icon on the bottom-right)
6. On the left side of your screen, under "Disabled" you should see a plugin named "Focus". Click on the plugin's toggle to enable it

### Troubleshooting 
If the plugin didn't appear when clicking refresh:
1. Press <code>esc</code> to head back to the main view
2. On the bottom-left side of your screen there should be an error, displaying why the plugin didn't load
Follow the guide based on what the error says:

- <code>Couldn't load [plugin name] because it is not compatible with the current API version</code>: You most likely have the wrong version of Tasker installed
To fix:
1. Go to the release page you downloaded the plugin from (if you followed the guide the page is [here](https://github.com/Rosepen-Studios/Focus/releases/latest))
2. At the top it should say which versions of the Tasker API the plugin is compatible with
3. Open Tasker and go to the settings (<code>⌘,</code> or click the gear icon at the bottom-left)
4. Click on <code>About</code> and find the field that says <code>API version</code>
5. If the version stated isn't supported by the plugin, you need to update Tasker or the plugin
6. On the [releases page](https://github.com/Rosepen-Studios/Focus/releases) try to find a version compatible with your version of Tasker and install it
7. If you don't find a compatible version of the plugin you can try updating Tasker
8. After updating find the new API version and search the [releases page](https://github.com/Rosepen-Studios/Focus/releases) for a compatible version of the plugin

- <code>Couldn't load [plugin name] because its plugin_id is the same as another plugin</code>: You might have a previous version of the plugin installed
1. In the plugins view search for a plugin with the same name as the one you are trying to install (Focus)
2. If you find it click on <code>Uninstall</code> and refresh the page

- Any other error is caused by an internal plugin error you can't fix. Please contact as about it [here](https://github.com/Rosepen-Studios/Focus/issues)
